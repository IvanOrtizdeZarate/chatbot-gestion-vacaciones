# Chatbot de Gestión de Vacaciones

## Descripción

Proyecto desarrollado para la materia Organización Empresarial.

El sistema simula el proceso de solicitud de vacaciones mediante un chatbot, automatizando las tareas previamente realizadas por Recursos Humanos.

## Tecnologías Utilizadas

- Python 3
- Streamlit
- JSON (persistencia simulada)

## Estructura del Proyecto

chatbot/
services/
data/
docs/

## Instalación

1. Clonar el repositorio

git clone <url-del-repositorio>

2. Ingresar al proyecto

cd chatbot-gestion-vacaciones

3. Instalar dependencias

pip install -r requirements.txt

## Ejecución

streamlit run app.py
